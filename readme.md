
# Git commands

cd --> current directory ( used to go inside the directory)
pwd--> print current directory( used to see the current working directory we are in)
nano filename.ext--> ( used to open a file, if it is not created it will first create the file and then open it)
cat filename.ext --> ( used to see the content of the file )
cd .. --> ( used to go out of the directory)
touch filename.ext --> ( used to only create the file )
